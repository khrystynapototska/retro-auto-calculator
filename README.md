# Лаб. 11 — Калькулятор вартості оренди (Vanilla JS) і QA

Відкрийте `index.html`. Логіка — `js/widget.js` (версія 2, із захистом).
`js/widget.v1-naive.js` — перша «наївна» версія, збережена лише для QA-журналу (на ній знайдені баги: NaN, Infinity, від'ємні суми). До сторінки не підключена.
Результати тестів: `test-results.json`; скрипт: `tools/test_lab11.py`. Параметри: авто, години (2–24), км (0–500), водій, оформлення, промокод `RETRO10`.
